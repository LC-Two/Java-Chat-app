# JavaFx Chat Application

A real time desktop chat application built to explore network programming and graphical interface in java

## Objective
I am building this project from scratch to learn **Socket Programming** and **JavaFX**. I have created this repo so that I can track the progess of my learning.

## Tech Stack
* **Language:** Java
* **UI Framework:** JavaFX
* **Networking:** 'java.net.Socket' and 'ServerSocket'
* **Environment:** Ubuntu, Intellij IDEA
